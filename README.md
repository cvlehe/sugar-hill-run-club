# Sugar Hill Run Club

A one-page static site for GitHub Pages. Open `index.html` to preview it locally.

## Publish

Add the contents of this directory to the root of a GitHub repository, including
`.nojekyll` and `assets/`. In **Settings → Pages**, choose **Deploy from a
branch**, select `main` and `/ (root)`, then save.

The next-run details and Instagram links are in `index.html`.
